**Vivian571 Unified Portal** 是一个集成了 4 个梯队、全部 8 个独立 Web 应用的一站式数字门户。所有站点均为纯前端实现（HTML5 / ES6+ / CSS3 / Canvas / WebP），**零构建依赖、本地优先（Local-First）、开箱即用**。

🔗 **线上访问入口（GitHub Pages）**：  
👉 [https://vivian571.github.io/vivian-portal/](https://vivian571.github.io/vivian-portal/)

### 梯队一：极速单页 Web 工具与视觉互动站
*极简体验、零上传隐私安全、极致交互*

1. **#01 Self-Inquirer · 拆掉假性学会**  
   - 极简费曼压力自检单页工具。输入任意技术或学科概念，通过五维作答、含糊词自动扫描与盲区雷达图，3 分钟戳破假性学会。
   - 核心特色：LocalStorage 零上传数据保留、五维雷达打分、AI 拷问官模式。
2. **#02 Solo Agency 2.0 · 一人公司开发看板**  
   - 基于第一性原理与多智能体协同的独立开发工作台。
   - 核心特色：内置 14 天 MVP 冲刺排期表、升级版 11 步执行手册、PRD 2.0 与多角色 Prompt 生成器、EDM 宣传曲歌词生成。
3. **#03 CuiMao · 360° 视线追踪互动艺术页**  
   - Big Sister is Watching You：移动鼠标或手指，画面中的人物视线会 360° 无缝跟随。
   - 核心特色：156 帧 WebP 精灵图平滑计算、近距离正面高清凝视、自定义光标与校准面板。

### 梯队二：垂直知识库、教程与高价值案例导航站
*高密度结构化数据、长期复利与探索价值*

4. **#04 自家版初中知识库 & 回溯大冒险闯关**  
   - 青岛版数学、外研版英语、统编版语文七年级上册共 83 个知识点节点 + 63 条先修依赖边查询系统。
   - 核心特色：知识图谱可视化、真实错因回溯链路、「有理数岛」答错自动溯源前置知识的闯关游戏。
5. **#05 OPC · 一人公司系列教程 & CLI 语音中枢官网**  
   - One Person Company 官方门户与命令参考手册。
   - 核心特色：涵盖 AI 模型版图、飞牛 OS 基础设施部署、Harness 工程与 OPC CLI 语音智能中枢命令速查。
6. **#06 Muse & AI 智能体真实高价值玩法合集**

   - 核心特色：中英双语即时切换、类别筛选、可直接复用的实操流程。

## 🚀 本地运行

无需安装 Node.js 或打包工具，任意现代浏览器或本地静态服务器即可运行：

```bash
# 进入目录
cd vivian-portal

# 使用 Python 启动本地测试服务器
python3 -m http.server 8080

# 打开浏览器访问
http://localhost:8080
```
